PI Buddy AI proxy

This is a serverless proxy that holds an Anthropic API key so PI Buddy's AI features (AI Diagnosis, AI Excel insight) can work without embedding a key in the static HTML file. It has no UI of its own.

Check status: /api/buddy (GET)

Configure by setting ANTHROPIC_API_KEY (and optionally PIBUDDY_APP_SECRET) under Project → Settings → Environment Variables, then redeploy.

In PI Buddy, click the ⚙️ button and paste this deployment's URL + /api/buddy as the Proxy URL.
